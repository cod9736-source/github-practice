# Packet Tracer 설정 출처

- 출처: https://app.notion.com/p/3e3ddb1a6377814098b1f6f3d4f9ad96
- 페이지 편집시각: 2026-10-02T02:27:47.708Z
- 추출 대상: Router 0·1·2, L3 Switch 0·1·2, Switch 2·3의 원문 설정 8개.
- 설정 파일은 노트의 입력 명령을 옮긴 자료다. 장비에서 추출한 running-config나 실제 실행 로그가 아니다.
- Switch 6·7은 노션에서 도면 기반 재현용으로 분리되어 있으므로 실제 설정 파일 추출 대상에서 제외했다.
- 원본 vlan-rip.pkt는 확보했지만 내부 설정·인증값을 점검하지 못해 공개 저장소에서 제외했다. 현재 configs는 노트 전사이며 .pkt에서 추출한 구성은 아니다.
- 단말 주소와 게이트웨이는 노션의 최종 구성도 표를 기준으로 한다. 초기 도면의 컴퓨터 2·3 중복 주소는 최종 표에서 각각 .3으로 수정되어 있다.
- 1.0.0.0/8~5.0.0.0/8은 과제의 가상 토폴로지 주소다. 실제 조직망용 사설 주소 설계로 제시하지 않는다.
- 미첨부 증거: show ip route 출력, VLAN/Trunk 상태 출력, 종단 간 ping 결과.
