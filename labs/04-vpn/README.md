# LAB 04 / NETWORK · 본사·지사 VPN

Sophos UTM의 Site-to-Site IPsec 입력 항목과 본사·지사 주소를 대칭으로 정리한 실습입니다.

| 구분 | 본사 | 지사 |
|---|---|---|
| 외부 주소 | 10.9.60.1/8 | 10.9.70.1/8 |
| 터널 대상 내부망 | 192.168.10.0/24 | 192.168.100.0/24 |
| Gateway | 192.168.10.254 | 192.168.100.254 |

Local/Remote는 현재 설정하는 장비 기준으로 바뀝니다. 상대 외부 주소는 터널 끝점이며, 상대 내부망은 터널을 통해 접근할 대상입니다. PSK는 실제 값 없이 관리합니다.

## 점검 순서

1. 단말의 주소·Gateway와 자기 Gateway 도달 여부
2. 양쪽 외부 주소 도달 여부
3. IPsec 상태와 협상 로그
4. Local/Remote networks·방화벽·단말 수신 조건
5. 실제 단말 주소를 사용한 양방향 통신

주소표와 GUI 입력 절차·설명 캡처가 근거입니다. 추가 회수한 실제 Remote Gateway 생성 화면에서 입력 항목과 저장 전 상태를 확인했습니다. 최종 IPsec 연결 상태, 터널 성립 로그, 양방향 단말 ping 출력은 미첨부이므로 VPN 통신 성공을 단정하지 않습니다. 추가 내부망 20·200 대역의 터널 포함도 미확인입니다.

## Troubleshooting

사용자는 **본사에서는 자기 Gateway까지 ping 가능, 지사에서는 자기 Gateway까지 ping 불가**라고 보고했습니다. 지사 내부 연결과 VPN 경유 통신을 나누어 점검할 상황이며, 확정 원인·수정 내역·해결 후 출력은 아직 확보되지 않았습니다.
