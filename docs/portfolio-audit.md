## 최초 점검에서 확인한 것

| 대상 | 확인 사실 |
|---|---|
| 개인 저장소 | `cod9736-source/github-practice`에는 연습용 `f1.txt`, `f2.txt` 두 파일이 있었음 |
| 개인 소개 | 최초 점검 때 계정과 같은 이름의 프로필용 저장소를 확인하지 못했으며, 이후 프로필 저장소와 소개문을 추가함 |
| 팀 프로젝트 | `Seo-Yeon-Choi/EduPOP`에는 애플리케이션 소스와 실제 개인 커밋이 있음 |
| 인프라 자료 | 점검 당시 개인 저장소와 팀 저장소의 확인 범위에는 인프라 설정·배포·검증 자료가 정리되어 있지 않았음 |
| 노션 실습 | 설정 원문·구성도·설명·학습 예제가 있었으며, 실습마다 완료 보고와 결과 증빙의 수준이 달랐음 |

팀 저장소는 본인 소유가 아니므로 이번 개인 인프라 정리의 수정 대상으로 삼지 않았습니다. 저장소 목록은 연결 방식마다 범위가 달라, 현재 조회되지 않은 자료가 모두 존재하지 않는다고 판단하지 않았습니다.

- 루트 소개에서 대표 실습 3개와 전체 실습 목록으로 이동하도록 연결합니다.

- 원문에서 확인한 값과 재실습을 위해 보완한 명령을 구분합니다.
- 검증 명령·정상 기준과 실제 확인된 결과를 구분합니다.
- 실제 비밀번호와 키를 공개 예제에 다시 포함하지 않습니다.
- 기존 연습용 텍스트 파일은 유지합니다.

`profile/README.md`는 Profile 소개문의 보관본입니다. 계정 소개는 `cod9736-source/cod9736-source`의 루트 `README.md`에서 제공합니다.

## 결과를 읽는 기준

| 표시 | 의미 |
|---|---|
| 설정 원문 확인 | 기존 기록에서 명령과 설정값을 직접 확인함 |
| 재실습 보완 | 읽기 쉽게 분리하거나 추가한 명령·설명이며, 당시 실행 사실과 구분함 |
| 사용자 완료·성공 보고 | 대화 또는 노트에 성공 보고가 있음. 원본 출력 확보와는 별개 |
| 결과 증빙 확인 | 해당 동작을 보여 주는 실제 출력·화면과 대응시킬 수 있음 |
| 확인 대기 | 결과가 없거나 대응 관계가 불명확하여 성공으로 표시하지 않음 |

이번 문서 정리는 실제 가상머신이나 클러스터를 재실행한 검증이 아닙니다. 대표 실습도 폴더별 확인 범위를 함께 읽어야 합니다. 수업 예제를 개인 운영 환경의 구축 성과로 확대하지 않았습니다.

## 다음에 보강할 증빙

1. 대표 실습의 설정 파일과 같은 버전으로 다시 구성한 결과.
2. 최종 웹 기능·데이터 저장·재조회·접근 제한을 보여 주는 실제 출력.
3. 중간 실패 이후 확정된 변경과 최종 재확인 결과가 연결되는 기록.
4. 재부팅 이후 서비스와 데이터가 유지되는지 확인한 기록.
5. 노션 링크의 비로그인 공개 열람 확인.

실제 결과가 확보되면 해당 실습의 상태를 갱신합니다. 예시 출력이나 예상 결과를 실제 검증 기록으로 채우지 않습니다.
