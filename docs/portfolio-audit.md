## 결과를 읽는 기준

| 표시 | 의미 |
|---|---|
| 설정 원문 확인 | 기존 기록에서 명령과 설정값을 직접 확인함 |
| 재실습 보완 | 읽기 쉽게 분리하거나 추가한 명령·설명이며, 당시 실행 사실과 구분함 |
| 사용자 완료·성공 보고 | 대화 또는 노트에 성공 보고가 있음. 원본 출력 확보와는 별개 |
| 결과 증빙 확인 | 해당 동작을 보여 주는 실제 출력·화면과 대응시킬 수 있음 |
| 확인 대기 | 결과가 없거나 대응 관계가 불명확하여 성공으로 표시하지 않음 |

## 다음에 보강할 증빙

1. 대표 실습의 설정 파일과 같은 버전으로 다시 구성한 결과.
2. 이름 조회·웹 응답·데이터 저장·접근 제한을 보여 주는 실제 출력.

4. 재부팅 이후 서비스와 데이터가 유지되는지 확인한 기록.

실제 결과가 확보되면 해당 실습의 상태를 갱신합니다. 예시 출력이나 예상 결과를 실제 검증 기록으로 채우지 않습니다.
