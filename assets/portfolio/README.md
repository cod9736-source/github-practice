## Layout

- Cover: 2400 × 600 pixels; labels, title, and subtitle placed within the central horizontal band.
- Thumbnail: 1600 × 1000 pixels; consistent lab number, category, title, technologies, and process footer.
- Font: DejaVu Sans; PNG renders preserve the intended typography when the font is unavailable on a viewing device.
- Base colors: background `#F7F8FA`, card `#FFFFFF`, text `#111827`, secondary text `#6B7280`, border `#E5E7EB`.
- Category accents: Network & Server / Containers `#2563EB`, Virtualization `#7C3AED`, Kubernetes `#0F766E`.
- Process footer: `DESIGN → BUILD → VERIFY → TROUBLESHOOT`.

Use the PNG files for Notion covers and image properties. Gallery image cropping and page cover cropping are separate; keep the dedicated thumbnail for the gallery where a separate image property is available.
