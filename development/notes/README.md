## 원본 보존 범위

- 문서 17개, 코드 블록 130개, 이미지 참조 899개, 첨부 파일 9개. 개발 토글의 본문 전체와 별도 복습·CS104 기록 포함.
- Database 영역 중 데이터 개념과 SQL 프로그래밍 기록 포함. 서버 설치·방화벽·백업 등 운영 설정은 Notion 인프라 문서에서 관리.
- 원문 코드의 오타·실습 단계·설명을 임의로 고치지 않고 보존. 전화번호로 보이는 값은 공개 문서에서 식별 가능한 대체값으로 표시.
- 이미지·첨부는 저장소 파일로 보존. 원본 북마크 14개는 확인된 제목과 Notion의 해당 블록 링크를 유지하며, 연결 도구가 제공하지 않은 외부 대상 주소를 추측하지 않음.

## 추가 원본 확인

기존 대화에 첨부된 `react_workspace.zip` 파일은 목록에서 확인했으나 파일 서비스의 다운로드 오류로 내용을 확보하지 못했다. 이 별도 ZIP은 위 보존 수량에 포함하지 않았으며, 현재 Notion의 React 본문·이미지는 모두 포함한다.
