CSS(Cascading Style Sheets): HTML 문서에 디자인을 적용하는 언어

Cascading : 위에서 아래로, 우선순위에 따라 스타일이 덮어쓰여지는 방식

주석 /* */ : CSS 문서에 주석을 작성할 때 사용

** CSS 적용 방식 (개발자가) **
1. 인라인 스타일 : HTML 태그 안에 style 속성을 사용하여 직접 스타일을 적용하는 방식
2. 내부 스타일 시트 : HTML 문서의 <head> 태그 안에 <style> 태그를 사용하여 스타일을 정의하는 방식
3. 외부 스타일 시트 : 별도의 CSS 파일을 만들어 HTML 문서에서 
                      <link> 태그를 사용하여 서로 연결하는 방식 (가장 많이 사용!)

** CSS 스타일 우선순위 : 적용범위가 작을 수록 우선순위가 높다 **
여러 스타일이 충돌할 때, 아래 순서로 우선 적용

!important : 그 어떤 스타일보다 우선 적용(단, 많이 사용 X)
인라인 스타일  
내부 스타일 시트 (아이디 > 클래스 > 태그 > 전체)
외부 스타일 시트 (아이디 > 클래스 > 태그 > 전체)
브라우저 기본 스타일(개발자가 설정하지 않은 기본값)

** 스타일 상속 **
부모 요소에 설정한 일부 스타일이 자식 요소에 자동으로 적용되는 것
ex) 글꼴, 글자색, 정렬 등
(단, 일부 속성은 상속되지 않음)
